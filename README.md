# Elanex Spices

Elanex Spices is a cardamom cultivator and seller website. The repository is
organized as a Vite/TanStack React frontend in `elanexUI` and a standalone
Sanity Studio in `elanexCMS`.

The frontend displays the marketing UI, reads the product catalogue from
Sanity, and sends contact enquiries through WhatsApp.

The first release is a marketing and portfolio website. It displays the
admin-managed product catalogue and product enquiries, but does not include
cart, checkout, ordering, payments, shipping, or customer accounts. Those
features can be added in a later ecommerce phase.

Product images and metadata are managed through the Sanity Studio. Contact
enquiries open WhatsApp with the visitor's form details prefilled.
